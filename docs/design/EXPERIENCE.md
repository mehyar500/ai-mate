# First-session experience

1. **Arrive:** original adult character, prerecorded voice sample, explicit AI label, free allowance and regional availability. No sexual public/checkout imagery.
2. **Join:** email sign-in, verified adult eligibility under the approved state policy, terms, character and optional nickname/tone. Start clean text. No microphone permission required for text. Verification cost belongs to acquisition for free accounts too.
3. **Remember:** ask before saving a useful fact. Visible memory panel supports correction, deletion and memory-off. Do not infer/save sexual preferences by default.
4. **Call:** show allowance, price and worker availability. Request microphone permission on press; explain that user camera is unused. Meter only after the first playable response connects.
5. **Adult opt-in:** approved US states only; valid server-verified age result, explicit opt-in and visible beta service hours. Reverify when policy requires. Failed/expired checks cannot unlock adult mode. Card ownership is not age proof.
6. **Pay:** hosted checkout shows currency, recurring amount, period, allowance, expiry and cancellation. Server events grant access. The character never uses guilt or threatened abandonment to sell.

The call screen needs face, captions, mute, end, time remaining and connection state. Warn at two minutes remaining; end at zero. No automatic top-up or hidden recording.

| Failure | User experience |
|---|---|
| Microphone denied | Keep text available; explain retry. |
| GPU warming/full | Honest wait estimate and cancel; no queued-time charge. |
| Avatar fails | Offer audio/static portrait; pause allowance deductions while degraded in the pilot. |
| Network drops | Show reconnecting; pause deductions; release worker after timeout; reuse session ID on recovery. |
| Clip fails | Bounded retry or restored clip entitlement; never debit twice. |
| Payment pending | Status refresh and safe retry without another purchase intent. |
| Cancel subscription | Confirm no renewal and show paid-through date. |

Require keyboard access, visible focus, readable contrast, reduced motion, captions and clear report/delete actions. The AI acknowledges it is AI and avoids exclusivity/dependency pressure or claims of professional care.
