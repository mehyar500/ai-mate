## Call arithmetic

3 turns/minute × 4,096 input tokens/turn = **12,288 input tokens/minute**. Output: 100 tokens/minute; TTS: 450 characters/minute. Thirty minutes: 368,640 input + 3,000 output tokens. Sixty: 737,280 + 6,000. Full history is billed again each turn.
Clean baseline: Qwen3-30B-A3B-FP8 $0.051/M input, $0.335/M output; Flux ASR $0.0077/minute; Aura-2 $0.030/1,000 characters. Managed-call moderation adds explicit Llama Guard input/output checks. [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/).
SFU $0.05/GB × 1.128 Mbps aggregate egress gives $0.000423/minute, including both audio directions and video. Shared free allowances are excluded from pricing. [SFU rates](https://developers.cloudflare.com/realtime/sfu/pricing/).
